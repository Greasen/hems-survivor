# HEMS Survivor 游戏设计

## 1. 游戏概念

《HEMS Survivor / 电量守卫》是一款能源调度题材的实时生存 Roguelike。玩家扮演家庭能源管理者，在太阳能发电不稳定、家庭需求持续变化、电价波动和突发事件中维持家庭系统运行。

核心感受是：平时做出高效规划，压力上升时在“现在省钱”和“保住系统”之间快速取舍。

## 2. 核心循环

```text
观察能源与需求
    ↓
调整 Battery / EV / Grid 策略
    ↓
每秒结算能源、金钱、家庭状态
    ↓
处理随机事件
    ↓
获得 Roguelike 升级并改变 Build
    ↓
应对更高难度与 Boss
    ↓
胜利或 Game Over 后重开
```

目标是让玩家在 30 秒内看懂基本循环，在 5～8 分钟的一局中逐步承受更高压力。

## 3. 能源系统

### Solar

太阳能发电来源。发电量受时间、天气和事件影响；白天通常提供能源，夜晚或阴天可能不足。

### Home

家庭实时负载。代表照明、家电和生活用电需求。负载会随时间和事件变化，不能完全关闭。

### Battery

核心缓冲资源。可以充电、自动管理或放电。电量过低会降低系统安全，电量过高则可能失去利用低价电或高价卖电的机会。

### EV

电动车既是可充电负载，也可以作为额外储能池。玩家需要在满足出行需求与支援家庭之间取舍。

### Grid

外部电网。允许玩家买电以避免断电，也可以在条件合适时卖电获取 Money。电价随时间和事件变化；是否允许买电、卖电是重要策略开关。

### 基础能量关系

```text
Solar → Home
Solar → Battery
Solar → EV
Battery → Home
Battery → EV
Grid → Home / Battery / EV
Home / EV / Battery → Grid（满足卖电条件时）
```

实际结算应优先满足 Home，再根据玩家策略分配 Battery、EV 与 Grid。

## 4. 玩家资源

### Money

通过卖电、完成事件或升级效果获得；通过从 Grid 买电、应急操作或部分事件损失。Money 是重要的短期效率指标，也是失败压力来源之一。

### Family

家庭满意度与安全感。能源短缺、长时间高价用电、关键需求未满足会降低 Family；稳定供电、完成家庭事件和选择保护型升级可以恢复或提高 Family。Family 降至 0 时 Game Over。

### Score

记录本局表现，用于比较和长期挑战。Score 可由存活时间、能源自给率、Money 结余、Family 状态、事件处理和 Boss 击破共同决定。

## 5. 玩家操作

MVP 计划提供清晰、低认知负担的控制：

- Battery：充电 / 自动 / 放电。
- EV：暂停充电 / 充电；后续可扩展 V2H 放电。
- Grid：允许买电 / 允许卖电。
- 事件：在限时窗口内选择处理方式。
- 升级：从三项随机候选中选择一项。

自动模式必须是可用的默认策略，让新玩家能观察系统；手动操作用于在高压时改变结果。

## 6. 时间与难度

建议初版节奏：

| 时间 | 体验目标 |
|---|---|
| 0～1 分钟 | 教学与建立安全感 |
| 1～3 分钟 | 简单事件，学习资源关系 |
| 3～5 分钟 | 价格、天气和负载造成压力 |
| 5～8 分钟 | 组合事件与高风险决策 |
| 8～10 分钟 | 混乱阶段或 Boss 压力 |
| 10 分钟以后 | 高难度生存，作为额外挑战 |

初版不要求每局都达到 10 分钟；应优先保证 5～8 分钟的节奏紧凑而可理解。

## 7. 随机事件

事件是改变局势、制造决策窗口的主要内容。每个事件至少包含：触发条件、持续时间、影响对象、玩家选项、即时结果和长期后果。

初版可包含：

- 阴天：Solar 输出下降。
- 高峰电价：Grid 买电成本上升，卖电收益提高。
- 家庭聚会：Home 负载短时间上升，Family 也更敏感。
- EV 紧急出行：EV 必须在截止时间前达到最低电量。
- 电网波动：买电或卖电暂时受限。
- 热浪 / 寒潮：家庭基础负载持续提高。

事件设计原则：

- 让玩家能理解因果关系。
- 给出至少一个有代价的可行选项。
- 避免纯随机瞬间杀死玩家。
- 事件频率和难度随时间增长，而非一开始堆满信息。

## 8. Roguelike 升级

每隔一段时间或完成关键事件后，玩家从 3 个随机升级中选择 1 个。升级应改变策略，而不只是线性加数值。

初版升级方向：

- 电池容量增加：提升缓冲能力，但充满速度或维护成本可能下降。
- 太阳能优化：提高 Solar 峰值输出，但天气波动影响更明显。
- 智能调度：自动模式更高效，手动干预收益降低。
- 家庭节能：降低 Home 负载，但可能减少 Score 或 Family 的某类收益。
- EV 优先协议：更容易满足出行需求，但家庭可用电量减少。
- 电价预测：提前显示短时间价格趋势。
- 应急备用：第一次严重断电时保护 Family，但消耗 Money 或升级机会。

升级池需要包含不同流派：稳定防守、卖电经济、Battery 依赖、EV 协同和事件控制。

## 9. Boss

Boss 是阶段性压力峰值，不应只是血量更高的普通事件。Boss 应持续改变能源规则，要求玩家提前准备 Build。

初版 Boss 示例：

- 极端天气周：Solar 长时间低输出，Home 负载持续增加。
- 电网危机：Grid 交易窗口随机关闭，必须依赖 Battery 与 EV。
- 超级高峰日：电价和家庭需求同时达到高位，卖电与保供之间冲突。

Boss 结束后应提供高价值奖励或显著的 Score 反馈，让玩家感到自己完成了一次阶段性考验。

## 10. Game Over 与胜利

### Game Over 条件

- Family 降至 0。
- 系统在关键负载下持续断电超过容错时间。
- Money 低于允许的应急阈值且无法买电（具体规则在原型阶段验证）。

Game Over 画面要告诉玩家：主要失败原因、关键时间点、能源流失位置和本局获得的升级，帮助玩家形成下一局策略。

### 阶段性胜利

初版可将存活到目标时间或完成 Boss 作为阶段性胜利。胜利不应立刻结束所有挑战，可显示 Score、Build 摘要和继续挑战入口。

## 11. 设计原则

- 信息透明优先：玩家应该知道数值为什么变化。
- 决策优先：每个重要按钮都应该有机会成本。
- 失败可学习：失败来自可复盘的选择，而非不可预测的秒杀。
- 内容克制：先用少量规则验证乐趣，再增加事件和升级。
- 手机优先：核心状态一眼可见，操作区域适合单手点击。
