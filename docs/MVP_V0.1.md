# MVP v0.1 需求范围

## 1. MVP 目标

做出一个“能完整玩一局”的最小版本，用于验证能源调度与 Roguelike 生存循环是否有趣。MVP 不追求完整内容、复杂美术或长期成长。

## 2. 必须包含

### 游戏循环

- 游戏开始、暂停、继续、重开。
- 以稳定 Tick 推进时间。
- 每秒结算能源、Money、Family 和 Score。
- 一局可以自然进入胜利或 Game Over。

### 能源对象

- Solar：按时间产生可变电量。
- Home：持续消耗电量，偶尔出现负载变化。
- Battery：显示当前电量与容量，支持充电、自动、放电。
- EV：显示当前电量，支持暂停和充电。
- Grid：显示实时买电 / 卖电价格，支持开关。

### 资源与反馈

- Money、Family、Score 的实时显示。
- 当前能源流向和主要消耗来源可读。
- 关键状态变化有颜色、图标或文字反馈。
- Game Over 显示原因和本局摘要。

### 事件

至少实现 4 类可重复触发事件：阴天、高峰电价、家庭负载上升、EV 紧急出行。每个事件都需要有明确提示和至少一个可操作选择或策略应对方式。

### Roguelike 升级

- 至少 3 次升级选择机会。
- 每次展示 3 个候选升级。
- 至少 6 个升级选项。
- 升级能够改变能源效率、容量、价格、事件或自动调度中的至少一个系统。

### 目标节奏

- 新玩家 30 秒内理解基础状态和主要按钮。
- 普通一局约 5～8 分钟。
- 难度随时间增加。
- 首个 Boss 或阶段性高压事件在约 5～8 分钟出现。

## 3. 暂不包含

- 账号、联网、排行榜和云存档。
- 复杂局外成长、每日任务和付费系统。
- 大量角色、地图、皮肤或装备系统。
- 多人模式。
- 复杂的物理模拟或真实电网模型。
- 高成本动画、完整音频包和商店级美术。

## 4. 建议的单屏信息布局

```text
顶部：时间 / Money / Family / Score

中部：Solar、Home、Battery、EV、Grid 的关系与当前数值

下部：当前事件、价格、警告和倒计时

底部：Battery 操作、EV 操作、Grid 开关

弹层：升级三选一、胜利、Game Over
```

## 5. MVP 验收标准

- 可以连续开始并完成 3 局，不需要刷新页面或重启 App。
- 能量、Money、Family、Score 在每个 Tick 后保持一致，不出现负数或无解释跳变。
- 玩家可以通过操作改变至少一次局面，而不是只能等待自动结算。
- 事件不会在没有提示的情况下直接造成 Game Over。
- 每次升级后，玩家能在状态或反馈中感知升级效果。
- Game Over 后能够重开，并保留合理的失败摘要。
- 开发者可以通过配置调整 Tick 速率、事件间隔、价格和难度。

## 6. 验证问题

完成 MVP 后必须通过试玩回答：

1. 玩家是否知道当前最危险的资源是什么？
2. 玩家是否明白为什么需要 Battery 和 Grid？
3. 三选一升级是否让每局产生不同策略？
4. 失败后玩家是否知道下一局要尝试什么？
5. 一局是否在无聊前进入新的压力阶段？
